⚓ Snap Marine — اسنپ دریایی (نسخه 1.2)
=====================================
پلتفرم جامع خدمات دریایی — یک فایل، بدون نصب، بدون برنامه‌نویسی.

فایل‌ها:
  index.html           خود پلتفرم (۱۸ ماژول، همه زیرماژول‌ها، داشبورد، فرم‌ها، نقشه، گزارش‌ها)
  snap-marine.sql      راه‌اندازی دیتابیس و امنیت — یک‌بار در Supabase اجرا می‌شود
  sw.js + manifest + icon-*.png   برای نصب به‌صورت اپ (PWA) و کار آفلاین

▶ همین حالا ببینید (بدون هیچ تنظیمی):
  روی index.html دوبار کلیک کنید → دکمه «مشاهده نمایشی». داده‌های نمونه بارگذاری می‌شود.

▶ راه‌اندازی واقعی (۳ قدم، حدود ۱۰ دقیقه):
  ۱) در supabase.com یک پروژه بسازید (رایگان).
  ۲) Supabase → SQL Editor → New query → محتوای snap-marine.sql را پیست کنید → Run.
  ۳) Supabase → Project Settings → API → «Project URL» و «anon public» را کپی کنید.
     index.html را باز کنید → «⚙️ تنظیمات اتصال» → این دو را وارد کنید → تب «ثبت‌نام» → ایمیل و رمز → ثبت‌نام.
     نخستین کاربر خودکار «ادمین» می‌شود. کاربران بعدی «در انتظار تایید» می‌آیند و شما در
     «داشبورد → مدیریت کاربران» نقش‌شان را تعیین می‌کنید.

  نکته: اگر در Supabase → Authentication → Providers → Email گزینه «Confirm email» روشن باشد،
  بعد از ثبت‌نام باید لینک ایمیل را بزنید. برای شروع سریع می‌توانید آن را خاموش کنید.

▶ انتشار برای دیگران (اختیاری):
  کل پوشه را روی هر هاست ایستا بگذارید — ساده‌ترین راه: app.netlify.com/drop (پوشه را بکشید و رها کنید).
  همکاران با همان URL و Anon Key وارد می‌شوند (یا آن را در «تنظیمات» ذخیره کنید و فایل را به آن‌ها بدهید).

▶ توسعه:
  - ماژول‌ها و زیرماژول‌ها در index.html، آرایه MODULES
  - فیلدهای هر موجودیت در شیء E (انواع: متن، عدد، تاریخ، انتخابی، ارتباط، تیک، لینک)
  - افزودن فیلد جدید = یک خط؛ فرم، جدول، جستجو و CSV خودکار به‌روز می‌شوند
